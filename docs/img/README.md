# docs/img

README/docs images:

- `lantern-lockup-light.png` / `lantern-lockup-dark.png` — README header lockup.
  These are the same file. The wordmark is white with a heavy near black outline,
  so one lockup carries on a white page and on GitHub's dark theme alike, and the
  two names exist only so the `<picture>` element in the README keeps its
  `prefers-color-scheme` source.
- `launcher.png` — Lantern launcher screenshot

The Lantern mark is a cyan storm lantern glowing in a deep navy night field, drawn
as a round badge with a near black outline. That is the only Lantern mark. Warm or
orange Lantern art is out of date and should not be reintroduced.
